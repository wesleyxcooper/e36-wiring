fuel-pump-hanger

Diagram

Radium Engineering 20-1170 fuel pump hanger + Walbro F90000267 (465 LPH E85) powered directly by Ecumaster PMU16 output O4 (25A, PWM-capable). O4 runs 12 AWG from PMU16 engine bay location through tunnel to hanger pump(+) stud. MaxxECU commands pump speed via CAN to PMU16 -- no external SSR needed. PWM: MTune Outputs → PWM fuel pump control, duty table by MAP/RPM. Phase 1 install -- carries through 07K Phase 3 with no re-work. Cross-reference power-distribution.wv (RADIUM_HANGER_STUB / W_PMU16_O4_PUMP) and fuel-pump-hanger-reference.md for full specs and MTune config. Install PDF: radiumauto.com/pages/instructions (20-1170).
