flex-fuel-sensor-phase1

Diagram

PHASE 1 flex fuel sensor wiring: GM/Continental 3-wire ethanol content sensor (GM 13577379 / Continental 21P1023) reads ethanol % + fuel temperature and outputs a variable-frequency signal to MaxxECU DIN 3.
Under Phase 1 the MaxxECU M50 pre-terminated harness exposes DIN 3 at the 16-pin aux breakout (pin 5 — labeled "GPO 7 / DIN 3"). The flex fuel signal wire terminates at this breakout pin. MTune Analog Inputs configured to interpret the pulse train as ethanol %.
Under Phase 3 (07K custom engine harness), the M50 harness is retired. The flex fuel signal moves to MaxxECU CMC C1 pin 9 (DIN 3) — same ECU input but different physical harness termination. See harnesses/flex-fuel-sensor-phase3.wv for that variant.
The SENSOR itself, its mount location (inline in fuel supply line between tank and engine), and the sensor pigtail wiring are IDENTICAL between phases — only the ECU-side termination changes.
Sensor part references:
GM 13577379 — Continental/VDO 21P1023 3-wire flex fuel sensor
Sold aftermarket by CJM Industries and similar shops for E85 conversions.
3-wire: +12V IGN (pin A), signal output (pin B), ground (pin C).
Signal: variable frequency 50-150 Hz proportional to ethanol %.

MaxxECU flex fuel documentation:
maxxecu.com/webhelp/settings-inputs.html (DIN inputs, frequency mode)
maxxecu.com/webhelp/settings-flexfuel.html (ethanol calibration table)

Fuel-pump-hanger relationship: this file covers ONLY the sensor signal wiring. Fuel pump power wiring is covered separately in harnesses/fuel-pump-hanger-phase1.wv (discrete relay era).
