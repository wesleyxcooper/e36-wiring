epedal-hella-6pv

Diagram

Hella 6PV010946-141 standalone floor-mount accelerator pedal wired to MaxxECU RACE via Deutsch Autosport AS-series firewall bulkhead. Phase 3 (07K engine). RHD fallback option -- use this harness if the BMW E46 pedal bracket (epedal-bmw-e46.wv) does not fit the RHD pedal box. Hella pedal is a universal floor-mount module with no OEM bracket dependency; mount position is fully custom-fabricated (aluminum plate + 3x M6 studs). MaxxECU has a native pre-defined profile for this pedal. Cross-reference docs/dbw-pinouts.md for specs and comparison.
