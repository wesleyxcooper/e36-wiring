Hella 6PV010946-141 standalone floor-mount accelerator pedal wired to MaxxECU RACE. Phase 3 (07K engine). RHD fallback option -- use this harness if the BMW E46 pedal bracket (epedal-bmw-e46.wv) does not fit the RHD pedal box. Hella pedal is a universal floor-mount module with no OEM bracket dependency; mount position is fully custom-fabricated (aluminum plate + 3x M6 studs). MaxxECU has a native pre-defined profile for this pedal. APS wiring is CABIN-TO-CABIN ONLY -- no firewall bulkhead crossing required (same as E46 variant). MaxxECU is cabin-mounted. Confirmed C2 pin assignments: APS1 → C2 E4 (AIN 6), APS2 → C2 F1 (AIN 7). Source: MaxxECU RACE GEN1 C2 pinout (maxxecu.com/webhelp/wirings-maxxecu_pinout.html). Cross-reference docs/dbw-pinouts.md for specs and comparison.
