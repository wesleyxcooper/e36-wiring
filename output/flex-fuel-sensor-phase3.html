flex-fuel-sensor-phase3

Diagram

PHASE 3 flex fuel sensor wiring: GM/Continental 3-wire ethanol content sensor (GM 13577379 / Continental 21P1023) — SAME sensor and same mount location as Phase 1 (see harnesses/flex-fuel-sensor-phase1.wv). What changes at Phase 3 swap moment is only the ECU-side termination.
Under Phase 3 the M50 pre-terminated harness is retired and replaced by the custom 07K engine harness (see harnesses/maxxecu-07k.wv). Flex fuel signal now terminates directly at MaxxECU CMC C1 pin 9 (DIN 3) — no intermediate 16-pin aux breakout in the path.
Rewiring at Phase 3 swap moment (minimal for flex fuel):
1. Disconnect the sensor's signal pigtail from the M50 harness 16-pin
aux breakout pin 5 (DIN 3).
2. Re-terminate that same signal wire into the custom 07K harness's
CMC C1 pin 9 direct contact.
3. Ground wire similarly re-terminates from 16-pin aux pin 2 to the
custom harness CMC C1 SGND pin (H1, pin 29).
4. +12V IGN supply wire — unchanged (still from OEM IGN rail via inline fuse).

The SENSOR itself and the shielded twisted-pair cable from sensor to ECU stay in place. Only the ECU end changes housing.
Sensor part references and MaxxECU documentation URLs: see harnesses/flex-fuel-sensor-phase1.wv (unchanged between phases).
Related fuel wiring at Phase 3:
- harnesses/fuel-pump-hanger-phase3.wv (PMU16 O4 direct-drive)
- harnesses/maxxecu-07k.wv (07K signal → CMC pin destinations)
