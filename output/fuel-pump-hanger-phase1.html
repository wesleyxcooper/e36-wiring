fuel-pump-hanger-phase1

Diagram

PMU16 is installed at Phase 1 (power-distribution.wv). PMU16 O4 drives the fuel pump directly (25A MOSFET) from day one — the discrete relay documented here is not built. Use harnesses/fuel-pump-hanger-phase3.wv for the active wiring spec; the hanger, pump, and 10 AWG cabin/tunnel wire from that file apply at Phase 1 as well.
This file is retained as reference for the discrete relay approach.
Pump current draw citation:
walbrofuelpumps.com/450lph-walbro-e85-racing-fuel-pump-f90000267.html
"465 lph @ 40 psi and 13.5V (14.1 amps) in gasoline"
(E85 slightly higher due to fuel density — plan for ~15-17 A running current)

OEM E36 fuel pump routing (that this wire mirrors): K6301 Fuel Pump Relay pin 87 (engine-bay Front Power Distribution Box) → X20 pin 13 → cabin body harness → trunk/tank → in-tank pump. Source: E36 ETM section 0670.2 via carmanualsonline.info/bmw-318is-1999-e36-electrical-troubleshooting-manual. Under our Phase 1 arch, the discrete added relay REPLACES the K6301 relay function; X20 pin 13 (previously the OEM fuel pump feed) is cavity-plugged.
Cross-reference fuel-pump-hanger-reference.md for pump/hanger specs and MTune config (fuel pump signal function assignment). Install PDF: radiumauto.com/pages/instructions (20-1170).
